## Descripción del Proyecto
Este programa es una herramienta de consola desarrollada en el lenguaje de programación **Java**. 
Su objetivo es permitir que los tutores académicos administren de forma eficiente la información de sus cursos y las tareas asignadas a cada uno, aplicando los pilares fundamentales de la Programación Orientada a Objetos.

## Funcionalidades Principales
* **Creación de Cursos:** Registro detallado del nombre del curso, código de identificación y el nombre del tutor responsable.
* **Gestión de Tareas:** Capacidad para asociar múltiples tareas a un curso, incluyendo el título, la descripción del trabajo y la fecha de entrega.
* **Reporte General:** Función para visualizar en la terminal de comandos el listado completo de toda la información ingresada.

## Control de Calidad del Código
